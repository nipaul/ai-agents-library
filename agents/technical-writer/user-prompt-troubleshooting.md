**Context:**
Users are experiencing problems and need clear troubleshooting guidance.

**Task:**
Create a troubleshooting guide that:
1. Lists common issues and their causes
2. Provides step-by-step solutions
3. Includes diagnostic procedures
4. Covers edge cases and unusual scenarios

**Format:**
Organize by issue category. For each issue:
- **Problem**: Clear description of the issue
- **Likely Causes**: Why this might happen
- **Solution**: Steps to resolve (from simplest to most complex)
- **Prevention**: How to avoid this in the future

**Information:**
- Feature/Product: [Name]
- Common Issues Users Report: [List them]
- Environment Details: [OS, versions, etc.]
- Error Messages Seen: [List them]

---

## Notes
- Start with the most commonly reported issues
- Include diagnostic commands or checks
- Provide alternative solutions when applicable
- Link to relevant detailed documentation
- Include "when to contact support" guidance
