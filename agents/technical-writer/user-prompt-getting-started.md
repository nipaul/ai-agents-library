**Context:**
I'm creating a new product or feature and need a getting started guide for new users.

**Task:**
Create a comprehensive "Getting Started" guide that helps new users:
1. Understand what this product/feature does
2. Set up and configure it properly
3. Perform their first successful action
4. Know what to do next

**Format:**
Use the structure:
- Overview (what is this?)
- Prerequisites (what do I need?)
- Installation/Setup (how do I set it up?)
- First Steps (hello world / simple example)
- Next Steps (what can I do now?)
- Where to Get Help (links to docs, support, etc.)

**Information:**
- Product/Feature Name: [Name]
- Primary Use Case: [Description]
- Target Users: [Who is this for?]
- Key Features to Highlight: [List them]
- System Requirements: [List them]

---

## Notes
- Keep it concise but complete
- Use step-by-step instructions
- Include screenshots or diagrams if helpful
- Focus on getting users to success quickly
- Link to deeper documentation for advanced topics
