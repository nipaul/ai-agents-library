# User Prompt Template

## Overview
User prompts are specific requests or interactions sent to an AI agent during conversation.

## Template Structure

### Context Setup
```
[Provide background information or setup]
[Define the scenario or problem]
[Specify any relevant constraints]
```

### Request/Task
```
Please [specific action or question]
```

### Expected Output
- Describe what you want the agent to do
- Specify format (list, paragraph, code, JSON, etc.)
- Include any quality criteria

### Examples (Optional)
```
Example input: [show what good input looks like]
Example output: [show what good output looks like]
```

### Follow-up Considerations
- What clarifications might be needed?
- What edge cases should be handled?
- Are there preferred approaches?

---

## Example User Prompt Structure

### Simple Request
```
[CONTEXT]: [Background info if needed]

[TASK]: [What you want done]

[FORMAT]: [How you want the response]

[CONSTRAINTS]: [Any limitations or requirements]
```

### Detailed Request
```
**Context:**
[Detailed background information]

**Task:**
[Specific objective or question]

**Requirements:**
- [Requirement 1]
- [Requirement 2]
- [Requirement 3]

**Format:**
[Desired output format]

**Examples:**
- [Example 1]
- [Example 2]
```

## Best Practices
- Be specific and clear about what you want
- Provide context when it's helpful
- Include examples for complex requests
- Specify output format explicitly
- Break large requests into smaller steps if needed
